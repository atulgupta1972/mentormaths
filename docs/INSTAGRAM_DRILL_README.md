## Story (8 beats · ~2.5s each)

1. Hook — forget the formula by morning?
2. The leak — tables, identities, last-minute revision
3. Mark the study plan → drills unlock
4. Formula drill — recall, don’t reread
5. Basics drill — tables · squares · cubes
6. Misses come back until they stick
7. Finish drills → today’s practice unlocks
8. CTA — mentormaths.in

## How to post

### Reel
1. Open Instagram → **+** → **Reel**.
2. Upload `mentor-maths-daily-drill-reel.mp4`.
3. Add a quiet trending audio (education / study / lo-fi).
4. Paste the caption below. Cover frame: slide 1 or 8.

### Carousel (looks like a PPT)
1. Instagram → **+** → **Post**.
2. Select `01.png` through `08.png` in order.
3. Same caption.
