Overview

End-to-end flow

  1. Admin configures pay per chapter (rate matrix).
  2. Admin assigns syllabus chapters to one uploader.
  3. Uploader gets an email — must review system carefully.
  4. Uploader agrees to rate, then uploads MCQ JSON.
  5. Uploader verifies every question (7 checks each).
  6. Admin publishes — only then students see content.

Admin · Step 1

Set chapter rates

  1. Login as Admin.
  2. Go to Teaching → Content upload tasks → Rate matrix.
  3. Add a row: Board + Class + amount (₹).
  4. Use Edit to raise rate for diagram-heavy chapters.

Admin · Step 2

Assign work

  1. Select class from top bar (e.g. Class 7).
  2. Teaching → Content upload tasks → Assign chapters.
  3. Pick uploader and textbook master.
  4. Tick syllabus chapters (one uploader per chapter).
  5. Optional: override rate or add notes.
  6. Click Create assignment(s) — uploader gets email.

Uploader · Step 2

Agree to rate

  1. Open My content tasks.
  2. Click the assigned chapter.

Uploader · Step 3

Upload chapter MCQs

  1. From task page, click Open textbook chapter.
  2. Upload chapter PDF if required.
  3. Use the AI prompt on the page to generate MCQ JSON.
  4. Paste JSON or upload ZIP pack → Import.
  5. Review imported questions on the same screen.
  6. Back on task page → Mark upload complete.

Uploader · Step 4

Verify each question

  1. Tick all 7 checks per question: text, options, correct, hint, explanation, difficulty, diagram.
  2. For diagram: tick even if “no diagram needed”.
  3. Progress saves — you can logout and continue later.
  4. When all done → All verified — lock verification.
  5. Then → Submit for admin publish.

This is the quality gate — do not rush.

Admin · Step 3

Publish to students

  1. Dashboard shows Content ready to publish.
  2. Review uploader’s chapter on textbook page.
  3. Publish MCQ sets when satisfied.
  4. Mark task published on content task page.

Students only see content after admin publish.
