# Content uploader guide

Screen-wise step guide for **admins** and **content uploaders** (textbook MCQ chapters).

## Open the guide

1. Open **`docs/content-uploader-guide.html`** in Chrome or Edge (double-click the file).
2. Scroll through slides — each slide shows a **wireframe screen** on the left and **steps** on the right.
3. **Print to PDF** (Ctrl+P) to share on WhatsApp or email.

## What it covers

| Phase | Who | Steps |
|-------|-----|--------|
| Setup | Admin | Rate matrix → Assign chapters |
| Start | Uploader | Email → Login → Agree rate |
| Upload | Uploader | Open chapter → Import MCQ JSON → Mark complete |
| Quality | Uploader | Verify every question (7 checks each) |
| Go live | Admin | Dashboard queue → Publish |
